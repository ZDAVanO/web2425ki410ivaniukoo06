## Deployment Instructions
To deploy this project on [Vercel](https://vercel.com), follow these steps:

1. Install Vercel CLI if not already installed:
    ```sh
    npm install -g vercel
    ```
2. Log in to Vercel:
    ```sh
    vercel login
    ```
3. Deploy the project:
    ```sh
    vercel
    ```
